# Nekomo App

Community-driven, open-source anime and manga apps and tools for Android and Android TV.

**Nekomo is in beta/alpha.** Builds are pre-releases for testers. Nekomo ships with **no sources installed**: you choose what to add, and Nekomo asks you to confirm every time.

## Projects

| Project | What it is |
|---|---|
| [**Nekomo**](https://github.com/Nekomo-App/Nekomo) | The app for phones and Android TV: discover, track, watch and read. Download the latest pre-release from [Releases](https://github.com/Nekomo-App/Nekomo/releases). |
| [**NEX**](https://github.com/Nekomo-App/NEX) | Nekomo Extension Exchange, a companion app to manage repositories, extensions and sources for Nekomo, Mihon, Aniyomi, CloudStream and Zangetsu. Has a built-in updater. |
| [Neko-Source](https://github.com/Nekomo-App/Neko-Source) | The Kotlin source code of the Nekomo apps. |
| [Nekomo-Docs](https://github.com/Nekomo-App/Nekomo-Docs) | Guides, FAQ and troubleshooting. |
| [Nekomo-Extensions](https://github.com/Nekomo-App/Nekomo-Extensions) | Supported formats and compatibility notes for external sources. |
| [Nekomo-Main-Web](https://github.com/Nekomo-App/Nekomo-Main-Web) | Source of the [website](https://nekomoapp.netlify.app). |
| [Nekomo-Branding](https://github.com/Nekomo-App/Nekomo-Branding) | Logos, icons and brand guidelines. |
| [Nekomo-DMCA](https://github.com/Nekomo-App/Nekomo-DMCA) | DMCA notice and legal information. |
| [Neko-Run](https://github.com/Nekomo-App/Neko-Run) | The pixel cat game on the website's 404 page. |
| [NekoShield](https://github.com/Nekomo-App/NekoShield) | Android network privacy and management app. |
| [OG-Kuro-No-Source](https://github.com/Nekomo-App/OG-Kuro-No-Source), [Nekomo-Web](https://github.com/Nekomo-App/Nekomo-Web) | Archives of the legacy Kuro No / Shiro projects and the retired website. |
